ตัดเกรด ป.พ.

ทำงานบนฐานข้อมูล Firebase เดียวกับนักเรียน งาน และคะแนนของระบบหลัก

ใช้ ↑ ↓ ← → หรือ Enter เลื่อนช่องคะแนน • Tab/Shift+Tab เลื่อนช่อง • วางข้อมูลจาก Excel ได้หลายแถวหลายคอลัมน์ • Ctrl/Cmd+C คัดลอกผลลัพธ์

ข้อมูลสำหรับกรอกระบบ SGS

ตั้งค่าระบบ

จัดการผู้ใช้งาน เทอม โฟลเดอร์ สำรองข้อมูล และการเชื่อมต่อระบบตัดเกรด

User Management

ขั้นตอน: 1) เพิ่มผู้ใช้ 2) กำหนดสิทธิ์ 3) ตั้งสถานะ Active

Usernameชื่อ-สกุลสิทธิ์สถานะจัดการ

Academic Term Management

ขั้นตอน: 1) กรอกปีการศึกษา 2) เลือกเทอม 3) เลือกว่าจะ copy ข้อมูลเดิมหรือไม่ 4) กดสร้างเทอม

ยังไม่มีเทอมในชีท Terms กด “สร้างเทอมจากค่าปัจจุบัน” เพื่อเริ่มต้น

Backup / Archive

เลือกเทอมที่ต้องการสำรองข้อมูลหรือ archive แล้วกดปุ่มดำเนินการ

Drive / Folder Settings

ขั้นตอน: 1) วาง Folder ID 2) กดตรวจสอบ 3) กดบันทึก ถ้าไม่ตั้งค่า ระบบจะใช้โฟลเดอร์เริ่มต้น CONFIG.FOLDER_ID

Manage Subjects

เพิ่ม/แก้ไข รายวิชาของแต่ละเทอม (ระบบจะกรองวิชาตามเทอมที่เลือก)

รหัสวิชาชื่อรายวิชาเทอมสถานะจัดการ

Teacher-Class-Subject Assignment

วิธีตั้งค่า 3 ขั้น: 1) เลือกครู 2) เลือกวิชา 3) เลือกระดับ/ห้อง แล้วกดบันทึก

TeacherSubjectClassTermStatusAction

Student Import Settings

ขั้นตอน: 1) ดาวน์โหลด template 2) กรอกข้อมูล 3) วาง CSV หรือ Sheet URL 4) Preview 5) Confirm Import
Column ที่ต้องมี: StudentID, Prefix, FirstName, LastName, Level, Room, No, Term

Grading System Integration

ระบบตัดเกรดถูกฝังอยู่ในแท็บ “ตัดเกรด ป.พ.” ของระบบหลักแล้ว ใช้ Firebase ชุดเดียวกัน ไม่ต้องตั้งค่า URL หรือเปิดระบบแยก

นำเข้านักเรียน (CSV)

Format: StudentID, Prefix, First, Last, Level, Room, No, Term
